# 约会与私密空间转场决策树

> 从约会开始到私密空间收尾的完整决策路径。
> 核心原则：在**高点转场**，不要在**低点勉强**。

## 决策树

```

│
├─ 阶段判断: 你们在第几场?

│   │   └─ [升温阶段]

│   │   └─ [试探转场] → "这附近有家不错的清吧，要不要去"
```

## 详细阶段说明

### 第一阶段: 前30分钟黄金法则

**前30分钟**: 只做一件事——建立舒适感。
- 不要急着触碰
- 不要夸她好看（=暴露需求感）
- 聊轻松话题：旅行、美食、爱好
- 用观察代替提问："你看起来像是做创意工作的"

**后30分钟**: 开始拉近距离。
- 轻度触碰：递东西时碰手、过马路时扶肩膀
- 降低物理距离：并排坐→面对面坐→斜对面坐
- 试探态度：她是否接受你的触碰？身体是否朝向你？

参考: [→ a_mikey_system.md A2 约会全流程](../modules/a_mikey_system.md)

### 第二阶段: 转场操作

**转场三步走（Mikey法）**:
1. 续摊提议："这附近有家不错的清吧，要不要去坐坐"（低承诺）
2. 第二场所继续升温（清吧/第二家餐厅）
3. 高潮时提出："我家就在附近，上去看看我养的猫"

**做局法（凡公子法）**:
1. 提前踩点——约会地点选在你家附近
2. 制造封闭空间——"我有个好玩的东西给你看"
3. 创造"顺其自然"的契机——不做口头谈判

参考: [→ a_mikey_system.md A2-转场回家技巧](../modules/a_mikey_system.md)
参考: [→ b_tankman_system.md B1-做局法](../modules/b_tankman_system.md)

### 第三阶段: ASD破解

女生犹豫的本质：她需要维护自我形象（"我不是随便的女人"）。

**破解三件套**:
1. **给台阶**："就只是坐坐" → 降低承诺，让她可以说服自己
2. **给理由**："上去看看我的猫/听一首歌/喝杯茶" → 具体且无害的理由
3. **给时间限制**："半小时我就送你回去" → 可预期的结束时间

**ASD破解禁忌**:
- ❌ 讲道理："都成年人了有什么不行的"
- ❌ 施压："你是不是不喜欢我"
- ❌ 放弃太快：她一犹豫你就撤退
- ✅ 温和坚持：给台阶+给理由+保持松弛

## IOI（兴趣信号）速查表

| 信号强度 | 行为表现 | 你的操作 |
|----------|----------|----------|
| 🟢 强IOI | 主动靠近、触碰你、笑得多、不玩手机、问你私人问题 | 可以转场 |
| 🟡 中IOI | 配合聊天、偶尔笑、偶尔看手机、不抗拒触碰 | 试探转场，再升升温 |
| 🔴 弱IOI | 一直看手机、身体后倾、话少、回避眼神 | 优雅结束，下次再约 |
| ❌ NO | 明确说不想、起身要走 | 立刻停止，保持风度 |

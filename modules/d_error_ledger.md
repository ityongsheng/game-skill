## Quick Self-Check

根据你的当前阶段，优先检查对应分类：

| 阶段 | 优先检查 | 最可能犯的错误 |
|------|----------|----------------|
| **新手期**（刚开始搭讪/约会） | D2 搭讪类 + D4 聊天类 | 背台词、查户口、秒回、不敢上前 |
| **有经验但停滞** | D3 约会类 + D5 心态类 | 过早暴露需求、过度温柔、单线投入 |
| **理论丰富但没结果** | D1 认知类 | 理论中毒、把女人当信仰、分不清名分和实质 |
| **被伤过/报复性放纵** | D5 心态类 | 报复性放纵、焦虑型依恋、过度分析 |

## D1. 认知类错误

| 错误 | 为什么错 | 怎么办 |
|------|----------|--------|
| 真心就能换来爱情 | 女人喜欢看综合价值（颜值、钱、社会价值），不是"对她好" | 把精力从"对她好"转向提升自己的价值 |
| 暗恋/不敢表达 | 默默付出+自我感动在女生看来很幼稚 | 喜欢就直接说，不藏着掖着 |
| 自我感动式深情 | 认为自己深情就能换来回报，活在自己的乌托邦里 | 感情不是电影，深情不是筹码 |
| 分不清名分和实质 | 认为必须先确定关系再发生关系 | 实质关系在前，名分在后 |
| 性爱不分离 | 认为没有感情就不能发生关系，错过窗口期 | 先推进实质性关系，再考虑感情 |
| 一次失败就彻底放弃 | 被伤害后认命躺平或走向极端 | 情感成长是渐进过程，多经历就改了 |
| 把女人当信仰 | 把女人当成神圣不可侵犯的对象 | 女人只是普通人，有七情六欲 |
| 性爱赋予过多意义 | 把发生关系等同于承诺和未来 | 不要把性看得太重 |

## D2. 搭讪类错误

| 错误 | 为什么错 | 怎么办 |
|------|----------|--------|
| 背台词式搭讪 | 缺乏真诚和灵动，显得做作 | 想到什么说什么，用日常对话的方式 |
| 眼神漂移 | 显得没自信、慌张 | 训练眼神锁定，看眉眼三角区 |
| 被拒后情绪崩溃 | 把单次结果等同于自我价值 | 当成概率游戏，拒绝是正常的 |
| 专门跑太古里去搭讪 | 把搭讪当成任务，显得刻意 | 把搭讪融入生活路径 |
| 过度纠缠 | 想用更多话挽回 | 对方拒绝立刻撤退 |
| 不敢上前/犹豫过久 | 错失窗口期 | 用3秒法则强迫自己行动 |
| 穿太正式/太花哨 | 显得目的性太强 | 穿日常轻松但整洁 |
| 语气高高在上 | 显得有压迫感 | 用平等的闲聊语气 |

## D3. 约会类错误

| 错误 | 为什么错 | 怎么办 |
|------|----------|--------|
| 过早暴露需求感 | 见面就夸"你好漂亮" | 保持神秘感，让对方猜你的意图 |
| 填补空白/怕冷场 | 冷场就紧张找话题 | 冷场是正常的，让对方也承受 |
| 过度温柔 | 温柔让人没感觉 | 要有张力，不要一味讨好 |
| ASD硬碰硬 | 女生拒绝转场就放弃 | 学会给台阶、合理化 |
| 问太多问题 | 给人查户口的感觉 | 多用陈述和观察 |
| 太晚转场 | 等到气氛冷下来才提议 | 在高点转场 |
| 请客太贵 | 过早展示高消费吓到对方 | 首次约会平价轻松 |
| 送太贵重的礼物 | 让女生有压迫感 | 关系没到不要送贵重礼物 |
| 吃饭时玩手机 | 不够专注 | 全程专注 |
| 吐槽前任 | 显得小气 | 不问不提 |

## D4. 聊天类错误

| 错误 | 为什么错 | 怎么办 |
|------|----------|--------|
| 查户口式聊天 | "你多大了" "你做什么工作" | 多用陈述和调侃 |
| 秒回 | 显得太闲/太在意 | 间隔5-10分钟回复 |
| 聊太久不约 | 想等到"关系够了再约" | 微信只用来铺垫 |
| 发长篇大论 | 想用文字打动对方 | 每条消息不超过30字 |
| 冷战/情绪化 | 对方不回就发火 | 保持情绪稳定 |
| 过度分析女生每条消息 | 把精力花在解读文字上 | 看行为，不听文字 |
| 给对方起外号太早 | 显得不够成熟 | 不要过早亲密称呼 |
| 频繁发"在干嘛" | 最无聊的开场白 | 用事情或观察开场 |

## D5. 心态类错误

| 错误 | 为什么错 | 怎么办 |
|------|----------|--------|
| 单线投入 | 把全部希望放一个人身上 | 同时接触3-5个人 |
| 害怕失去任何人 | 把一个女生当成唯一 | 建立女生储备池 |
| 结果导向 | 一次搭讪失败就崩溃 | 享受过程，接受概率 |
| 自我设限 | "我不够帅/不够有钱" | 行为线索 > 颜值 > 财富 |
| 报复性放纵 | 被伤害后变成把妹机器 | 找到技术与真诚的平衡 |
| 理论中毒 | 学了太多框架、推拉、价值展示 | 回归对人的真诚兴趣 |
| 焦虑型依恋 | 女生不回消息就胡思乱想 | 不把安全感建立在对方回复上 |
| 完美主义 | 非要等到完美时机才行动 | 先做再优化 |
